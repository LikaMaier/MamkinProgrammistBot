# Telegram-магазин услуг по установке ПО

Бот + Telegram Mini App: каталог услуг, доп. услуги, календарь записи по МСК, оформление заказа, онлайн-оплата, напоминания и полноценная админка — всё внутри Telegram, на телефоне и ПК.

**Стек:** Python 3.12 · aiogram 3 · aiohttp · SQLite · один процесс (бот + веб-сервер Mini App).

## Что умеет

**Клиент**
- Каталог основных услуг с описанием, ценой и длительностью; можно выбрать несколько.
- Шаг с дополнительными услугами (можно пропустить), итог считается автоматически.
- Календарь с доступными датами и сетка свободного времени (МСК). Занятые слоты недоступны; длительность заказа учитывается — длинная работа не встанет туда, где не помещается.
- Подтверждение: состав, сумма, дата/время, телефон, комментарий.
- Уведомление в чат после записи, напоминания за 24 ч и за 1 ч.
- «Мои записи»: предстоящие и история, перенос, отмена (до дедлайна), оплата, «Повторить заказ».

**Администратор** (вкладка «Админ» в приложении, команда `/admin`)
- Заказы с фильтрами по статусу, данными клиента (имя, @username, телефон), сменой статуса: новый → в работе → выполнен / отменён. Клиент получает уведомление о каждом изменении.
- Мгновенное уведомление о новом заказе в Telegram с кнопками смены статуса прямо в сообщении.
- Услуги: добавление, редактирование, скрытие, удаление; цены и длительность для основных и доп. услуг.
- Расписание: рабочие часы по дням недели, шаг слота, горизонт записи, минимальное время до записи; выходные даты и ручное закрытие отдельных слотов.

**Оплата** (по желанию): Telegram Stars или ЮKassa через платёжного провайдера Telegram.

## Запуск на Railway

1. Создайте бота в **@BotFather** и скопируйте токен.
2. Залейте папку в новый GitHub-репозиторий и создайте в Railway сервис из этого репозитория.
3. Railway → сервис → **Settings → Networking → Generate Domain** — получите адрес вида `https://xxx.up.railway.app`.
4. Добавьте **Volume** с mount path `/data` (иначе база будет стираться при каждом деплое).
5. В **Variables** задайте:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен бота |
| `ADMIN_IDS` | ваш Telegram ID (узнать — команда `/id` в боте); несколько — через запятую |
| `WEBAPP_URL` | адрес из шага 3 |
| `DB_PATH` | `/data/shop.db` |
| `SHOP_NAME` | название магазина (необязательно) |
| `PAYMENT_MODE` | `off`, `stars` или `provider` |
| `PAYMENT_PROVIDER_TOKEN` | токен ЮKassa (только для `provider`) |
| `STAR_RATE_RUB` | сколько ₽ в 1 звезде (для `stars`, по умолчанию 1.8) |
| `CANCEL_DEADLINE_HOURS` | за сколько часов клиент может сам отменить/перенести (по умолчанию 2) |

6. После деплоя напишите боту `/start`. Кнопка «Магазин» появится и в меню чата.

Шаблон переменных — в `.env.example`.

## Онлайн-оплата

- **Telegram Stars**: `PAYMENT_MODE=stars` — больше ничего не нужно. Сумма в рублях пересчитывается в звёзды по `STAR_RATE_RUB`.
- **ЮKassa**: @BotFather → ваш бот → Payments → ЮKassa → получите токен → `PAYMENT_MODE=provider` и `PAYMENT_PROVIDER_TOKEN=…`.

После записи у клиента открывается окно оплаты; оплатить можно и позже из «Мои записи». Оплаченные заказы помечаются, админ получает уведомление.

## Локальный запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN=... ADMIN_IDS=... WEBAPP_URL=https://<туннель, например ngrok>
python main.py
```

Для проверки вёрстки в обычном браузере без Telegram: `DEV_MODE=1` и откройте `http://localhost:8080` (не включайте на продакшене).

## Структура

```
main.py        — запуск: бот (polling) + веб-сервер + напоминания
api.py         — HTTP API для Mini App, проверка подписи Telegram initData
logic.py       — слоты, запись, перенос, отмена, статусы, счета на оплату
db.py          — SQLite: услуги, заказы, пользователи, расписание (+ стартовые услуги)
handlers.py    — команды бота, кнопки статусов, приём платежей
notify.py      — тексты и рассылка уведомлений
reminders.py   — напоминания за 24 ч и 1 ч
webapp/index.html — весь интерфейс Mini App (клиент + админка)
```

## Как расширять

- Новые поля заказа — колонка в `orders` (db.py) + `ORDER_FIELDS`, вывод в `notify.order_text` и `index.html`.
- Несколько мастеров — добавить таблицу мастеров и `master_id` в заказ, фильтровать `busy_orders` по мастеру.
- Промокоды, отзывы, оплата после выполнения — отдельные эндпоинты в `api.py` по тому же образцу.
- При росте нагрузки SQLite легко заменить на PostgreSQL: весь SQL собран в `db.py`.
